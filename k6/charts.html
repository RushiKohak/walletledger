WalletLedger — k6 transfer results

This page contains no measurements of its own. Every value below is computed from the k6 JSON export you load, in this browser tab: nothing is uploaded, requested or stored, and the page works from the file system with no server and no dependencies.

Drop k6 JSON exports here or choose files — e.g. k6-results-run1.json. Load two or more runs to compare them.

No run loaded

Export a run, then load the file above:

k6 run --out json=k6-results-run1.json k6/transfer.js

--out json=… writes one JSON object per sample, which is what makes a per-second view of throughput and latency possible. A --summary-export file only holds end totals and cannot be charted over time.

Percentiles use the nearest-rank method on the samples in the file. These pages are only as meaningful as the conditions of the run; record machine, Docker limits, DB_POOL_SIZE, VUs and duration next to any number you publish.
